# wildcoVoyages
James Wild &amp; Co Voyages — the Voyages volume, served at jameswildco.com/voyages/.

- `voyages/` — the static site (25 pages, assets, map data, robots.txt, sitemap.xml, llms.txt)
- `vercel.json` — sends / to /voyages/ and keeps everything noindex until launch

The house site (jpapagno-ux/JamesWildcompany) rewrites jameswildco.com/voyages/* to this project.
Canonical URLs on every page point to https://jameswildco.com/voyages/.
